개인정보처리방침

시행일: 2026년 11월 6일

1. 도구의 목적

“결고운 문장 업로더”는 유튜브 채널 「결고운 문장」의 운영자가 자신의 채널에 직접 제작한 영상을 업로드하기 위해서만 사용하는 개인용 도구입니다. 일반 사용자에게 제공되지 않습니다.

2. 이용하는 정보

YouTube Data API를 통해 운영자 본인 채널의 영상 업로드 권한과 채널 기본 정보(채널 ID, 이름)만 사용합니다. 다른 사람의 개인정보는 수집하지 않습니다.

3. 보관과 공유

인증 정보는 운영자의 컴퓨터에만 저장되며 제3자에게 제공하거나 판매하지 않습니다. 운영자는 Google 계정 설정(보안 → 타사 액세스)에서 언제든 권한을 철회할 수 있습니다.

4. Google API 서비스 사용자 데이터 정책

이 도구의 Google API 정보 사용은 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 문의

유튜브 채널 「결고운 문장」의 채널 정보를 통해 문의할 수 있습니다.
